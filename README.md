Analyzed Swiggy restaurant and order data to identify customer behavior, sales trends, restaurant performance, and operational insights. Performed data cleaning and transformation using Excel and Power Query, conducted analytical queries using SQL, and developed interactive Power BI and Tableau dashboards using DAX-driven KPIs and visualizations.
